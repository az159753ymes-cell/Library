# 高雄市立五甲國中圖書館系統 專案 UI 與協作規範

## 一、 圖示與按鈕設計規範
1. **純圖示按鈕無外框原則**：
   * 當按鈕僅包含「純圖示」（無文字說明，例如頁頭的 ⚙️ 齒輪設定按鈕）時，預設**絕對不加外框與陰影**（移除 `border` 與 `shadow`），呈現與標題融為一體的無縫視覺體驗。
   * 僅保留懸停微互動（如 `hover:bg-[#EAF0EC]`）與淡化樣式。

2. **禁止使用彩色 Emoji 圖示（以向量圖示 SVG 為主）**：
   * 系統介面視覺設計**一律優先使用 SVG 向量圖示**（或質感純文字），禁止隨意使用作業系統預設彩色 Emoji（如 🏫、📅、⚙️ 等），保持畫面精緻典雅專業。

## 二、 自動備份規範
3. **自動複製備份資料夾原則**：
   * 每次執行版本升級或重大程式調整前，助手必須自動於 Desktop 複製一份當前版本的專案備份資料夾（例如另存為 `圖書館系統_vX.Y.Z_備份`），自動確保專案歷史版本安全無虞。

## 三、 輪換表格空白與活動欄位顯示規範
4. **空白儲存格與七年級首時段顯示規範**：
   * 當班際輪換尚未建立任何書箱時，儲存格必須維持**完全空白**（絕對不顯示「未分配」、「點擊指定」等說明文字）。
   * 七年級首時段預設未指定書箱時，僅直接精簡顯示「**參觀圖書館＆新生齊步走**」，不加上「來自【圖書館】的《...》」或括號備註文字。

5. **儲存格雙行移交說明統一規範**：
   * 無論是教師手動指定書箱或隨機分配書箱，凡包含書籍之儲存格一律統一顯示雙行移交卡片：
     * 行 1：`來自【上一個地點】的《書名》`
     * 行 2：`請於【規定時間】移交到【下一個地點】`
   * 手動指定與隨機分配透過底色區隔（指定為暖木色 `#F5EFEA`；隨機為柔綠色 `#EAF0EC`），均絕對不加外框。
